## 🌟 Fitur-Fitur Unggulan

### 1. Halaman Beranda (Home)
* Logo dan identitas resmi **SMP Negeri 19 Palembang**.
* Tombol aksi cepat:
  * ⚡ **Main Demo**: Langsung memainkan kuis campuran lintas mata pelajaran tanpa registrasi.
  * 🎮 **Masuk Sebagai Siswa**: Bergabung ke ruang kuis menggunakan Room PIN.
  * 🎓 **Login / Dashboard Guru**: Kelola kuis, bank soal, dan analitik.
  * 📖 **Petunjuk Penggunaan**: Panduan lengkap bagi guru dan siswa.
* **Katalog Mata Pelajaran**: 14 kategori mapel Fase D plus tombol **Tambah Mapel Baru** kustom.

---

### 2. Dashboard Guru & Manajemen Asesmen
* **Statistik Real-time**: Total kuis, bank soal, jumlah peserta, rata-rata nilai, dan ketuntasan KKTP.
* **Buat Kuis Baru**: Formulir lengkap dengan pilihan mata pelajaran, jenjang kelas, topik/materi, Tujuan Pembelajaran (TP), durasi timer, tingkat kesulitan, kategori asesmen, dan mode permainan.
* **Bank Soal Terintegrasi**: Filter berdasarkan mata pelajaran, tingkat kesulitan, pencarian kata kunci, serta penambahan dan penghapusan butir soal.
* **✨ AI Question Generator**: Fitur cerdas pembuat soal otomatis sesuai Kurikulum Merdeka Fase D dengan klasifikasi kognitif Bloom (C1-C6/HOTS), kunci jawaban, dan pembahasan mendalam. Dilengkapi modal review dan edit sebelum disimpan ke kuis/bank soal.
* **Template Kuis Siap Pakai**:
  1. *Ice Breaking Ceria* (5 soal santai awal pelajaran)
  2. *Review Materi Kilat* (10 soal komprehensif)
  3. *Asesmen Formatif Standar* (15 soal KKTP Fase D)
  4. *Tantangan HOTS Analisis* (10 soal analisis pemecahan masalah)
  5. *Remedial Bertahap* (8 soal berjenjang dengan petunjuk)
  6. *Pengayaan Eksploratif* (12 soal tantangan tinggi)
* **Import & Ekspor Excel/CSV**:
  * Impor banyak soal sekaligus dari file CSV/Excel dengan format kolom standar:  
    `No | Pertanyaan | A | B | C | D | Kunci | Pembahasan | Materi | Level`
  * Tombol unduh file contoh template CSV.
  * Ekspor rekap nilai siswa ke format file CSV/Excel.
  * **Cetak Laporan Resmi**: Dilengkapi format Kop Surat Resmi Dinas Pendidikan Kota Palembang dan SMP Negeri 19 Palembang.

---

### 3. Ragam 6 Mode Permainan
1. **Classic Quiz**: Siswa bermain mandiri dengan penilaian berbasis akurasi dan kecepatan.
2. **Team Battle**: Siswa dibagi menjadi 4 kelompok (Tim Merah, Biru, Hijau, Kuning) dengan papan skor tim akumulatif.
3. **Race (Balapan Avatar)**: Avatar siswa melesat di lintasan sirkuit balap setiap kali menjawab benar menuju garis finish.
4. **Survival Mode**: Siswa memiliki 3 nyawa (❤️❤️❤️). Jawaban salah mengurangi 1 nyawa; uji ketelitian tingkat tinggi!
5. **Streak Master**: Menjawab benar berturut-turut menghasilkan bonus multiplier (+20, +30, +50 poin) dan efek api membara.
6. **Relax Mode (Latihan Formatif)**: Tanpa batasan waktu dan tanpa peringkat, berfokus penuh pada pembahasan konsep materi secara ramah.

---

### 4. 10 Ragam Tipe Soal
1. **Pilihan Ganda**: 4 pilihan jawaban bergaya warna dan bentuk geometris Kahoot (Segitiga Merah, Belah Ketupat Biru, Lingkaran Kuning, Kotak Hijau).
2. **Benar / Salah**: Dua tombol pilihan tegas (Benar / Salah).
3. **Pilihan Ganda Kompleks**: Multi-select checkbox untuk soal dengan lebih dari satu jawaban benar.
4. **Menjodohkan**: Pasangan stimulus-respon interaktif.
5. **Urutkan**: Kartu interaktif untuk menyusun tahapan atau urutan kronologis/logis.
6. **Jawaban Singkat**: Kolom input isian teks dengan pencocokan istilah kunci dan toleransi spasi/huruf besar-kecil.
7. **Tebak Gambar**: Pengungkapan gambar bertahap.
8. **Soal Berbasis Gambar**: Stimulus diagram, peta, atau foto ilmiah di atas pertanyaan.
9. **Soal Berbasis Video**: Penayangan video materi singkat sebagai stimulus soal.
10. **HOTS (Higher Order Thinking Skills)**: Format khusus studi kasus, analisis data, evaluasi, dan pemecahan masalah kontekstual.

### 5. Mode Presenter / Layar Guru di Proyektor Kelas
* Guru menekan tombol **"Buat Room (Host)"** untuk menghasilkan **Room PIN 6-Digit** unik (misal: `738421`).
* Layar proyektor menampilkan kode PIN besar dan daftar siswa yang bergabung secara live.
* Terdapat tombol **"Simulasi +4 Siswa Bergabung"** untuk demonstrasi kelas instan.
* Dilengkapi kontrol presenter:
  * ▶ Mulai Kuis
  * ⏸ Jeda / Lanjut Timer
  * ⏭ Soal Berikutnya
  * 📊 Statistik Jawaban Kelas
  * 🏆 Podium Peringkat Juara 1, 2, 3
  * 🔇 Pengaturan Suara
  * 🏁 Akhiri Permainan & Simpan Laporan
* **Sinkronisasi Antar-Layar Real-time**: Menggunakan `BroadcastChannel` dan `StorageEvent` browser. Guru membuka layar host di satu tab, dan siswa/peserta membuka tab lain dengan PIN yang sama; keduanya terhubung secara langsung tanpa jeda!

### 6. Power-Up, Gamifikasi, dan Refleksi Siswa
* **Power-Up Permainan (Opsional Guru)**:
  * ✂️ *50:50*: Menghilangkan dua opsi yang salah.
  * ⏳ *Extra Time*: Menambah 10 detik waktu berpikir.
  * ✨ *Double Point*: Melipatgandakan poin soal menjadi 2x.
  * 🛡️ *Shield*: Melindungi streak jika menjawab salah.
  * 💡 *Hint*: Menampilkan petunjuk edukatif dari guru.
* **Gamifikasi**: Poin skor, streak multiplier api 🔥, animasi confetti kemenangan, dan lencana prestasi (FIRST WIN, STREAK MASTER, QUIZ HERO, KNOWLEDGE EXPLORER, SEMPURNA).
* **Refleksi Pembelajaran Siswa (Section AH)**:
  Setelah kuis selesai, siswa mengisi lembar refleksi emosional dan kognitif:
  * 😊 Saya sudah paham
  * 😐 Saya cukup paham
  * 🤔 Saya masih perlu belajar
  * 🆘 Saya membutuhkan bantuan  
  Dilengkapi kotak uraian untuk materi yang membingungkan dan hal yang disukai.
